# 光明节

「光明节」（希伯来语 **חֲנֻכָּה**，Hanukkah，字面意为「奉献」），又称**献殿节**、**修殿节**，自犹太历**基斯流月（Kislev）二十五日**起，连续八天。

节期纪念公元前二世纪马加比（Maccabees）家族率领百姓反抗塞琉古王朝安提阿古四世（Antiochus IV）的宗教压迫，收复耶路撒冷圣殿并重新奉献。传统记载：圣殿重献时，只找到一小罐未被玷污的灯油，本只够燃一日，却奇迹般地燃了八日——因此节期的核心是**点灯**：使用九枝灯台（chanukiah），每晚加添一支，直至第八夜八灯齐明；同时诵念「赞美诗」（Hallel），并在每餐后加添「感恩」（Al HaNissim）。
